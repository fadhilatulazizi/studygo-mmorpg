- [x] Define product boundary and initial architecture.

- [ ] One field, one monster type and one combat loop.

- [ ] Instance lifecycle, AOI and reconnect.
- [ ] Party and dungeon prototype.
- [ ] Load tests and observability.

## Phase 4 — Social and PvP
- [ ] Guilds, chat safety, report and block.
- [ ] Asynchronous arena, then real-time PvP if validated.

## Phase 5 — Commerce and operations
- [ ] Trading pass, listings and atomic transfers.
- [ ] Moderation tools, fraud monitoring and support workflows.
- [ ] Production deployment, backup and incident runbooks.
